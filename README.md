# LuckyChain-Solana 

A decentralized lottery application built on **Solana** using **Rust** and the **Anchor framework**.  
This project demonstrates how to create fair, transparent, and tamper-proof lottery systems powered by blockchain.

---

##  Features
-  **Buy Lottery Tickets** with SOL
-  **Random Winner Selection** using Solana-native randomness
-  **Transparent & Secure** with on-chain execution
-  **Written in Rust** using Anchor for program development
-  **React Frontend** to interact with the lottery smart contract

---

##  Tech Stack
- **Solana** blockchain
- **Rust** for smart contracts
- **Anchor** framework
- **React + TypeScript** frontend
- **Phantom Wallet** integration
